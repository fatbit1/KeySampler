KeySampler is an independent plugin and is not made or supported by ISLA Instruments or Roland. Page references marked "S2400 manual" refer to the ISLA S2400 User Manual (July 2026); "DSP manual" refers to the S2400 DSP Card User Manual (March 2025); "PCR manual" refers to the PCR-M30/M50/M80 Owner's Manual.

1Overview

KeySampler sits on a DSP bus like any other plugin. It listens to the audio that the S2400 sends into that bus, records it when you arm it, and then plays the recording across the keyboard: the Root Note plays the sound at its original pitch, keys above and below transpose it.

Features

  • Records the bus input; starts automatically when sound arrives, stops after 0.4 s of silence (max 30 s)
  • Every recording gets its own number (1–9999), saved with the S2400 project
  • 16-voice polyphony, velocity, pitch bend, sustain pedal, portamento and legato glide
  • One Shot, Gate, Loop and Ping-Pong play modes with start and loop points in the S2400's own time format
  • ADSR envelope
  • Built-in sine, triangle, square and sawtooth oscillators (Sample 0–3)
  • Moog-style 24 dB/oct ladder filter per voice (low, band, high pass) with drive, self-oscillation and its own ADSR envelope
  • LFO with delay to pitch (vibrato), filter (wah) or volume (tremolo); pan, expression
  • MIDI CC control laid out for the Edirol PCR-M30 GM2 map
  • Thru keeps the bus passing its normal audio

Signal flow

The track's audio goes into KeySampler's bus. Thru passes it on unchanged; the filter and pan only affect KeySampler's own notes.
Where sounds come from. The DSP Card cannot read the S2400's SD card or sample memory. It only receives parameter values and, through Sync Files, the contents of SD:/dspcard/. KeySampler therefore gets its sounds by recording the bus input, or from WAV files placed in its own samples folder.

2Installation

What you need

  • An S2400 with the ISLA DSP Card installed
  • A computer to copy one folder to the SD card (only for installing or updating the plugin)
  • The plugin folder keysampler.lv2, containing keysampler.so, keysampler.ttl, manifest.ttl and a samples folder

Copy the plugin to the SD card

  1. Put the S2400's SD card in your computer.
  2. Copy the keysampler.lv2 folder into dspcard/plugins/lv2/ on the card (the folder where your other DSP plugins are). It must sit directly inside lv2, not in an extra sub-folder:
    SD card / dspcard / plugins / lv2 / keysampler.lv2 / keysampler.so
    SD card / dspcard / plugins / lv2 / keysampler.lv2 / manifest.ttl  …
  3. When updating, delete the old keysampler.lv2 folder first so no old files remain.
  4. On a Mac, remove the hidden files Finder adds, then eject the card (replace SDNAME with the card's name):
    find /Volumes/SDNAME/dspcard -name ".DS_Store" -delete
    dot_clean /Volumes/SDNAME

Transfer it to the DSP Card

  1. Put the SD card back in the S2400.
  2. Press Shift+Effects (8th key in the top row), scroll to the DSP Card section and select Sync Files (DSP manual p. 6). Wait until it finishes.
  3. Switch the S2400 off and on again. The DSP Card only builds its plugin list at start-up.

Load it on a bus

  1. Press Bank+0 to open the DSP Mixer.
  2. Press Shift+Pad on a bus to open Bus Settings, select +Add Plugin/Preset and choose KeySampler (listed under the vendor KeySampler).
  3. Highlight KeySampler and press Enter to open its parameters.
32 parameters in the menu. The S2400 shows only the first 32 parameters of a plugin. KeySampler puts the 32 most-used ones there (chapter 10); the rest keep sensible defaults and several of them can be changed from a MIDI controller.
After an update that adds or changes parameters, remove KeySampler from the bus and add it again, then re-enter its settings in each project that uses it. Recordings are not affected.

3Quick start

This records a pad and plays it from the keyboard in about a minute.

  1. Choose the bus. Load KeySampler on bus 1 (see MIDI routing below).
  2. Route the pad to it. Hold Shift and press the pad you want to sample to open Track Settings (S2400 manual p. 56). Set Output to 1. Hit the pad: you hear it through KeySampler because Thru is on.
  3. Record. Tick Record (or press L1), hit the pad once, then untick it (or press L1 again).
  4. Play. KeySampler gives the recording a new number and selects it: Sound shows Sample when you re-open the page. Play the keyboard. Middle C (note 60, the default Root Note) plays the sound at its original pitch.

Routing a track to a bus

With the DSP Card installed, each of the S2400's eight outputs feeds the DSP bus with the same number (DSP manual p. 3). A track's Output in Track Settings therefore selects the bus. Stereo samples play through an output pair: a stereo sound set to output 1 or 2 uses buses 1 and 2. Make that pair stereo in Bus Settings (Mix), or set the track's Output Mix to L+R Mixed to keep it on one bus (S2400 manual p. 56). In Mixer fader mode the output number of each track is shown above its fader (S2400 manual p. 25).

MIDI routing

The DSP Card gives each bus its own MIDI channel (from the card's configuration): bus n receives channel n, a stereo pair receives the channel of its first bus (1+2 → 1, 3+4 → 3, …), and every bus also receives channel 16. KeySampler itself plays notes on any channel it is given. So to play KeySampler on bus 3, set the keyboard (or MIDI track) to channel 3, or to channel 16 — but channel 16 reaches every KeySampler at once.

Keep the bus to yourself while recording. Everything that plays into KeySampler's bus is recorded, so route only the pad you are sampling to that bus during a take.

4Recording

KeySampler records whatever arrives at its bus input. Each recording is stored as a new sound with its own number; nothing is ever recorded over.

How a recording starts and ends

StageWhat happens
ArmedTurning Record on arms the recorder. Nothing is stored until the input is louder than Rec Threshold dB (default −50 dB).
RecordingStarts at the first sample above the threshold, including 32 samples (about 0.7 ms) captured just before it, so the attack is not cut.
Automatic stopAfter 0.4 s below the threshold, or when 30 s have been recorded.
Manual stopTurning Record off ends a recording immediately.
Clean-upTrailing silence is trimmed to 50 ms after the last loud sample and the end gets a short fade-out.
SavedThe recording gets the next free number and is written to the DSP Card as sample_NNNN.wav (16-bit stereo, 48 kHz). KeySampler plays it at once, sets Sound to Sample and keeps the number in the hidden Sample ID parameter, so saving the project keeps it.

To record another take, turn Record off and on again. Turning it on while a recording is being saved has no effect.

Threshold

  • If background noise or a reverb tail keeps the recording running (the new sound only plays once it ends), raise Rec Threshold dB, or turn Record off to end the take.
  • For very quiet sounds, lower it towards −80 dB.

Thru

Thru (always on; not in the S2400 menu) passes the bus input to the bus output unchanged, so the bus behaves normally. With Thru off, the bus only outputs KeySampler's notes. Thru does not affect recording.

Mono buses record mono; a stereo bus pair records stereo. The recorded level is the bus input level before KeySampler's Level, filter and pan.

5Sample numbers and projects

Sound chooses what KeySampler plays. Its menu lists, in order:

SoundPlays
Sine, Triangle, Square, SawThe built-in oscillators. They are part of the plugin, so they can never be recorded over or deleted. New KeySamplers start on Sine, a handy test that notes arrive.
SampleThis KeySampler's sound: your latest recording, or the last recording you picked by number, whichever came last. After you record, Sound shows Sample. The number is kept in a hidden parameter, Sample ID, that the S2400 saves with the project like any other. Before the first recording or pick, Sample is silent.
1 – 9999Any recording on the DSP Card by its number, including ones made in other projects. Picking a number that exists also makes it this KeySampler's Sample.

Every recording gets the next unique number and is stored on the DSP Card under that number, as sample_0001.wav, sample_0002.wav … Because Sound and Sample ID are saved with the project, loading it brings back exactly the sound it was saved with.

A recording keeps its number for good, so each project keeps its own sounds.
SituationBehaviour
New recordingGets one more than the highest number ever given out, even if that recording was deleted, so an old project never finds someone else's sound under its number. After 9999, deleted numbers are reused, lowest first. Existing sounds are never overwritten.
Choosing a soundSet Sound to a number to play that recording, and leave it there to use it in this project (the project then saves the number). One sound at a time per KeySampler; switching stops notes still sounding.
Unused numberSilence.
StorageOn the DSP Card's internal storage. Recordings survive power-off, Sync Files and plugin updates. They are not on the SD card, so they do not move with a project to another S2400.
After recording, re-open KeySampler's page: Sound should read Sample. Then save the project. If it still shows the old value, the S2400 did not receive it (this happens only with two KeySamplers whose settings are all identical): change any setting on one of them and record again.

Oscillators

The oscillators make KeySampler a simple synth. Root Note plays middle C (261.63 Hz); the waveforms are band-limited per octave, so high notes stay clean. They sustain while a key is held and stop on release whatever the Mode; Start and loop points don't apply. Everything else (envelopes, filter, vibrato, glide, CC control) works as usual. Recording works on any Sound setting and switches to the new recording (Sound = Sample).

Deleting recordings

The DSP Card has no file browser, so KeySampler deletes its own recordings:

  1. Scroll Sound past Sine … Saw and Sample to the number of the recording you want to remove, and play it to be sure.
  2. In Changes, select Delete.

The recording is removed from the card at once, Sound goes back to Sample, and Changes goes back to ---. Because picking the number also made it the Sample, Sample returns to the one it played before you picked it. Projects that used the deleted number play silence. There is no confirmation, but Delete only works on a sound picked by number: with Sound on Sample or on a waveform it does nothing, so the recording a project is using can't be deleted by accident. WAVs added with Sync Files are left alone (remove those from the SD card and sync).

Recordings from earlier versions

Versions up to 0.18 stored recordings by Bank and Slot. The first time 0.20 starts, it renames them: Bank b, Slot s becomes Sample b×100 + s (Bank 1 Slot 3 → 103, Bank 12 Slot 5 → 1205). Recordings made with 0.19 keep their numbers. Open each older project, set Sound to the new number and save it again.

From 0.20–0.31 to 0.32: those versions named files after the internal Sample value, so the first recording was sample_0004.wav and showed as “4”. The first time 0.32 starts it renames every recording to the number the menu now shows (sample_0004.wav → sample_0001.wav, sample_0027.wav → sample_0024.wav) and leaves a file numbered_from_1 so it only does this once. Projects keep playing the same sound; only the label changes (“27” now reads “24”). The Sample range grew by three, so in a project saved with a recording above about 1660 the value may come back one or two numbers off: check it and save again.

From 0.32 and earlier to 0.33: the Sound list gained the Sample entry, so a project saved with a recording number now shows the next lower one (a project on “24” plays recording 23). Open it, set Sound to the right number (or record again) and save. File names do not change.

Adding WAV files with a computer

Name a WAV sample_NNNN.wav (four digits, e.g. sample_9000.wav), copy it into SD:/dspcard/plugins/lv2/keysampler.lv2/samples/ and run Sync Files; Sound 9000 then plays it. A recording with the same number takes priority, so use numbers your recordings won't reach (e.g. 9000 and up). Supported: 8/16/24/32-bit PCM and 32/64-bit float, mono or stereo, any sample rate; loop points stored in the WAV (smpl chunk) are used in Loop mode.

6Playing, envelope and sample points

Playing

ParameterDescription
LevelOutput volume of KeySampler's notes, 0–2 (1 = unity).
Root NoteThe note that plays the sound at its original pitch (default 60 = middle C).
Tune±24 semitones, fractions allowed (0.5 = 50 cents).
Bend RangePitch-bend range in semitones (0–24, default 2). Not in the S2400 menu.
Vel SensNot in the S2400 menu (default 1 = full velocity response). 0 = all notes at full volume. Gain = (1 − s) + s × (velocity/127)².
VoicesPolyphony limit, 1–16. Set 1 for mono lines. When all voices are busy, releasing voices are reused first, then the oldest. Replaying a held note retriggers it.
ModeOne Shot plays to the end and ignores note-off (drums). Gate fades out with Release when the key is let go. Loop repeats the loop section while the key is held, then fades out. Ping-Pong does the same but plays the loop section forwards and backwards in turn, so the loop never jumps.

The sustain pedal (CC64) holds notes in Gate, Loop and Ping-Pong modes.

Glide: portamento and legato

Glide ModeBehaviour
OffEvery note starts at its own pitch.
PortamentoEvery new note slides from the previous note's pitch to its own, also when the previous key was already released. Works with any number of Voices; with Voices = 1 the slide starts from wherever the sounding note currently is.
LegatoMono. While a key is held, a new key does not restart the sound or the envelope: the pitch slides to the new note. Releasing it slides back to the most recent key still held. A note played with no key down starts normally, without a slide.

Glide ms (0–2000, default 100) is the time a slide takes, whatever the interval. In Legato, 0 gives instant pitch changes without retriggering, the classic "hammer-on" feel.

Envelope

Attack ms (0–2000), Decay ms (0–5000), Sustain (level 0–1) and Release ms (0–5000) shape each note's volume. Attack and decay are linear ramps; release fades from the current level. With Sustain 0 in Gate, Loop or Ping-Pong mode, a note ends after its decay.

Start and loop points

Each point uses two whole-number parameters, sec and ms, matching the S2400's waveform editor, which shows points as minutes:seconds.milliseconds+samples (S2400 manual p. 30). The sample-accurate "smp" parts exist but sit beyond the S2400's 32-parameter menu, so in the menu points move in 1 ms steps.

S2400 showsKeySampler parameters
0:01.250+24sec = 1, ms = 250 (the +24 samples are dropped)
0:00.500+0sec = 0, ms = 500
  • Start sets where every note begins.
  • Loop Start and Loop End set the section repeated in Loop and Ping-Pong mode.
  • Loop End at 0:00.000+0 means end of the sound; so does any value past the end.
  • With Loop Start and Loop End both at 0, a WAV's own loop points are used if it has any, otherwise the whole sound loops.
  • Samples are counted at the sound's own sample rate (48 per ms for recordings).
Editing tips. Each encoder click changes a whole-number parameter by one step. For big moves, highlight the parameter and use Fader 8, or F1/F2/F3 for 25/50/75 % (DSP manual p. 11). A knob assigned to Start, Loop Start or Loop End sweeps across the whole sound, which is quick for finding a loop by ear before fine-tuning it here. If a loop clicks, nudge its points by a few ms or samples.

7Filter, LFO and pan

These affect only KeySampler's notes, never the Thru signal.

Filter

ParameterDescription
FilterOff, Low Pass, Band Pass (mid) or High Pass. A 4-pole transistor-ladder filter in the style of the Moog, on each note: 24 dB/octave, with saturation inside the feedback loop, so loud sounds and high resonance growl and distort. Band and High Pass are mixed from the ladder stages.
Cutoff0–100, spread musically: 0 = 20 Hz, 50 ≈ 630 Hz, 100 = 20 kHz (frequency = 20 × 1000Cutoff/100 Hz). Changes glide over about 10 ms, so sweeps are smooth.
Resonance0–1. The cutoff frequency gets louder as you turn it up; from about 0.87 the filter self-oscillates: it whistles a sine at the cutoff frequency on top of the sound, which you can play by sweeping Cutoff. As on a Moog, high resonance thins the bass; KeySampler gives part of it back.

Filter envelope

The filter runs separately on every note, so each note can have its own sweep. A second envelope moves the cutoff: cutoff = Cutoff + envelope × F.Env Amount. F.Env Amount 0 switches it off (the default).

ParameterDescription
F.Env Amount−100 to +100, in Cutoff units; 0 = off. +60 with Cutoff 20 opens the filter to 80 at the envelope's peak; negative values close it instead.
F.Env Attack / Decay msTime to reach the peak (0–2000 ms) and to fall to the sustain level (0–5000 ms).
F.Env SustainLevel held while the key is down, 0–1.
F.Env Release msTime to fall to zero after release, 0–5000 ms.

The filter envelope restarts with each new note, except legato notes, which keep the running sweep. It only acts when Filter is not Off. Typical pluck: Low Pass, Cutoff 20, Resonance 0.3, Amount +60, Attack 5, Decay 400, Sustain 0. Acid bass: Saw (Sample 3), Low Pass, Cutoff 15, Resonance 0.8, Amount +50, Decay 200, Sustain 0, Glide on.

LFO: vibrato, filter wobble, tremolo

One LFO (a sine, running separately on every note) can move the pitch, the filter cutoff or the volume. Press B4 to choose: Pitch → Filter → Volume → Pitch. KeySampler starts on Pitch.

ParameterDescription
LFO Rate HzSpeed, 0.1–12 Hz (default 5). PCR knob R3.
LFO Depth0–100 (default 0 = off). PCR knob R4. Pitch: up to ±100 cents. Filter: up to ±30 Cutoff units (±3 octaves) around Cutoff; Filter must be on. Volume: 100 dips fully to silence, 50 to half.
LFO Delay msTime after note-on before the LFO starts, 0–2000 ms; it then fades in over 200 ms. Not in the S2400 menu: PCR knob R5.
LFO DestPitch / Filter / Volume. Not in the S2400 menu: B4.

Pan and expression

Pan (−1 left to +1 right) is a balance control: the centre leaves both sides at full level. Listen on the main mix (Mix Out, headphones, USB main): every DSP bus, mono or stereo, reaches the main mix in stereo, but an individual output jack carries only the left channel of a mono bus. On a stereo pair (set Mix in Bus Settings, DSP manual p. 9) output jacks 1&2 carry left and right. The expression pedal (CC11) scales KeySampler's output from 0 to full; it starts at full.

8MIDI control, Save and Restore

Many parameters can be controlled from MIDI controllers. The assignments follow the PCR-M30 GM2 set (chapter 9, appendix A) and are the same in every project.

Save and Restore

Moving a knob, slider or button changes only the sound. The S2400 menu keeps its values, and those menu values are what the project saves. You decide what happens to your changes, from the keyboard or from the menu:

CommandWhat it does
Save
L2 (CC 81), or menu Changes → Save		Writes every value changed from a controller into the S2400 menu. Save the project afterwards to keep them.
Restore
L3 (CC 82), or menu Changes → Restore		Forgets all controller changes: KeySampler goes back to the saved settings, i.e. the values in the menu. The sound (Sound, Sample ID) is not changed.
Delete
menu Changes → Delete		Deletes the recording picked by number in Sound (see chapter 5). Does nothing when Sound is Sample or a waveform.
Default
menu Changes → Default		Puts every other setting back to its factory default, in the menu too. The sound itself (Sound, Sample ID), Record and Changes are not changed. Save the project to keep it; reload the project to undo it.
  • Changing a value in the menu also takes over that one parameter, so the last thing touched is what you hear.
  • Save sends the values to the DSP Card's audio engine (sushi), exactly as the menu does. Start and loop points are sent as sec / ms / smp; a Loop End at maximum is sent as 0:00.000+0 (end of sound).
  • The S2400 shows the saved values when you re-open the plugin page. Two KeySamplers with identical settings cannot be told apart, and Save does nothing for them.
  • Changes (the last menu item) acts about a second after you select Save, Restore, Default or Delete, then goes back to --- (shown when you re-open the page). The short wait means passing over an entry while browsing does nothing, but there is no confirmation. A value saved in a project is never acted on when it loads.
  • The hidden Auto Menu Sync (off) would copy every controller move to the menu instead.

Setting L1–L3 on the PCR (once)

In the GM2 set, L1–L3 send Stop / Start / Continue. Those are transport messages: the S2400 would start and stop its own sequencer, and they do not reach a plugin as button presses. Set them to control changes and save the result as a user memory (PCR manual p. 63, 59, 84):

  1. Select memory 0 (GM2). Press EDIT, press L1, then ENTER.
  2. Press the CONTROL CHANGE key, ENTER. Enter the MIDI channel of KeySampler's bus (chapter 3), ENTER. Enter 80, ENTER. Press 0 (Latch mode), ENTER.
  3. Repeat for L2 with 81 and L3 with 82.
  4. Press EDIT, the SAVE key, ENTER, choose memory 1, ENTER. Use memory 1 from now on; everything else is the same as the GM2 set.
Check on your S2400. Whether it forwards aftertouch (S2), program change (B1/B2), RPN (R6/R7) and SysEx (B6) to the DSP bus is not confirmed. If a control does nothing, use the menu.

11Troubleshooting and limitations

ProblemWhat to check
KeySampler is not in the plugin listRun Sync Files, then power-cycle the S2400. Check the folder is dspcard/plugins/lv2/keysampler.lv2/ with the files directly inside, no extra sub-folder, no zip. Remove .DS_Store files. Look under the vendor KeySampler or All vendors.
The pad is not heard through the busThe track's Output must match KeySampler's bus number; Thru must be on.
The keyboard plays nothingSet Sound to Sine: a sine tone should sound. If it does not, the notes are not reaching this bus: set the keyboard to the MIDI channel with the bus number (or channel 16).
Record does nothingNothing reached the bus above the threshold: check the pad's Output and lower Rec Threshold dB.
Recorded but nothing playsThe recording may still be running (noise or a long tail keeps it open): turn Record off. If it never starts, lower Rec Threshold dB. Check that Sound is on Sample or on the recording's number.
A project plays the wrong soundThe project was saved before the recording reached the menu. Re-open KeySampler's page, check that Sound is Sample, and save the project again.
Waveforms play, recordings are silentA Start or Loop point is past the end of the recording (oscillators ignore those points, recordings don't). Check Start / Loop Start / Loop End, or use Changes → Default, which resets them and keeps the sound.
Pan has no effectThe bus is mono. Make its pair stereo in Bus Settings (Mix).
Loop does nothingMode must be Loop. Loop End 0 means the end of the sound; check the points are inside the sound's length.
A knob does nothingCheck the PCR is on memory 0 (GM2 set) and on the bus's MIDI channel. If it still does nothing, the S2400 is not forwarding that type of message.
The menu does not follow a knobThe S2400 redraws the page only when it is opened: leave and re-open it. With two identical KeySamplers, change one setting on one of them so they can be told apart.
Settings changed after an updateParameters may have been renamed or reordered. Remove and re-add the plugin and re-enter settings.

Known limitations

  • The sound itself stays on the DSP Card; the project stores only its number.
  • Recordings live on the DSP Card only (not on the SD card).
  • The S2400 file browser does not show the dspcard folder, so adding WAV files to the samples folder needs a computer. Recording from the bus does not.
  • After Save the S2400 shows the new values only when the plugin page is re-opened.
  • Maximum recording length 30 s; maximum point position 59.999 s.

AMIDI implementation

KeySampler receives MIDI from the S2400 through its LV2 event input. It does not transmit MIDI. All messages are accepted on every channel (omni). Running status and system real-time messages are handled by the host and are not used.

A.5 Program change

Program change is used for two buttons: a number lower than the previous one steps the Filter type (B1, "program change dec"), a higher one steps the Mode (B2, "inc"). A repeated 0 counts as lower, any other repeated number as higher; the first program change received counts as lower if it is 0.
